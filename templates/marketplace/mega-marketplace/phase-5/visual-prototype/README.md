# Phase 5 - Visual Prototype

Template: Mega Marketplace  
Status: draft visual prototype

## Goal

Create a visible, navigable prototype before integrating the template into Lyra
or the production app.

This prototype is intentionally static. It exists to validate the marketplace
experience and visual direction first.

## Screens Included

- Home
- Catalog
- Product detail
- Cart grouped by vendor
- Checkout with backend quote rules

## How To Open

Open:

`preview.html`

## Rules

- Do not use external marketplace brand names in UI copy.
- Keep the public storefront search-first.
- Keep product cards consistent and scannable.
- Cart and checkout must show vendor grouping.
- Checkout must remain backend quote-first.
- Lyra should later adapt this structure with client-specific copy, colors,
  categories, products, images, and brand tone.

## What This Is Not

- Not connected to backend yet.
- Not the final production UI.
- Not the vendor/admin dashboard visual prototype yet.
- Not the final Lyra rendering path.
