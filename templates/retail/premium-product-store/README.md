# Premium Product Store

Runtime prototype for a single-vendor premium product storefront.

Use this template when the business sells:

- One flagship product
- A small curated product line
- Premium electronics, accessories, equipment, devices, tools, or launch products
- High-ticket products that need strong storytelling and specification proof

Do not use this template for:

- Broad multi-category stores
- External seller marketplaces
- Listing/classified marketplaces
- Restaurant menus
- Appointment booking businesses
- Simple company brochure sites

Implemented runtime pages:

- Home
- Product detail
- Specs comparison
- Cart
- Checkout

Commerce model:

- Single owner
- Owned inventory
- Single-store checkout
- Payment-ready
- Shipping-tracking-ready
- Customer-account-ready
- Store-admin-products-ready

AI rules:

- Lyra may rewrite product names, headlines, model copy, specification values, and CTA copy.
- Lyra must keep the selected premium product structure unless the user asks to change template family.
- Lyra must not paste raw client notes directly into the page.
- Lyra must output structured JSON conforming to the manifest data contracts, not raw HTML/CSS/JS.
