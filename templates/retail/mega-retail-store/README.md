# Mega Retail Store

Runtime-enabled template for a large single-owner store.

Use this when the business sells many categories or many products, but all
products belong to the same business owner. This is not a multi-vendor
marketplace.

## Scope

- Broad catalog and deal discovery
- Search, filters, categories, cart, checkout
- Owned inventory and single-store order flow
- Customer accounts and store-admin inventory pages planned

## Not Scope

- External seller onboarding
- Vendor storefronts
- Vendor payout ledger
- Split orders by seller

Those belong to `templates/marketplace/mega-marketplace`.
