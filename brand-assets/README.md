# Kit vectorial de marcas VM

Archivos maestros editables y escalables. Todos usan `viewBox`, grupos con ID y
formas vectoriales nativas; no contienen imágenes rasterizadas.

## Archivos

- `vm-mark.svg`: símbolo VM.
- `vm-horizontal.svg`: símbolo y nombre VM Business Systems.
- `listo-mark.svg`: símbolo geométrico Listo.
- `listo-horizontal.svg`: símbolo y nombre Listo.
- `kreaton-mark.svg`: símbolo K de Kreaton.
- `kreaton-horizontal.svg`: símbolo y nombre Kreaton + Lyra.

## Colores maestros

- VM navy: `#06172F`
- VM green: `#087443`
- Listo emerald: `#087443`
- Listo deep: `#045A34`
- Kreaton blue: `#1261C9`
- Kreaton deep: `#083D91`

Los textos permanecen como texto editable con Manrope. Antes de enviar un arte
final a imprenta, duplica el archivo y convierte el texto a curvas/contornos en
tu programa de diseño para evitar sustituciones de fuente.
